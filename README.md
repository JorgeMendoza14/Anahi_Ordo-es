# Multiservicio Escolar Anahí

App web (HTML/CSS/JS, sin dependencias) para un multiservicio escolar, en blanco y verde.

- Servicios (copias, color, anillado, plastificado, escaneo, etc.)
- Cotizador de impresiones con descuento por volumen
- Tienda de útiles con búsqueda y categorías
- Carrito que envía el pedido por WhatsApp

Abre `index.html` en el navegador. Cambia el número de WhatsApp en `app.js` (`WHATSAPP`) y los precios en `SERVICES` / `PRODUCTS`.
